# 《Star Rover Odyssey 2.0》星際巡航：互動式 JavaScript 遊戲化教學平台

版本：2.0  
語言：正體中文  
目標對象：高中普通班學生、零程式基礎  
開發技術：Vue 3 + Vite + Three.js + Pinia  
部署平台：Cloudflare Pages  
產品定位：**遊戲優先、程式概念逐步揭露**的互動式 JavaScript 探索平台

---

## 🌟 產品核心特色

1. **填空寫真的 JavaScript，即時 3D 回饋**：
   - 每關從「把 ___ 填好」開始，學生寫的是真正的 JavaScript，在 Web Worker 沙箱裡執行，結果立刻驅動 3D 場景。
   - 預測 ➔ 寫程式 ➔ 執行 ➔ 觀察 3D 結果 ➔ 讀錯誤說明 ➔ 修正 ➔ 通關後用出場券檢核觀念。
2. **全站亮色系視覺美學**：
   - 清爽珍珠白與淡天藍背景、白色卡片、柔和品牌藍與丁香紫點綴。
   - 3D 太空場景全面升級為明亮星雲與星球探索風格，高親和力且符合學校電腦教室友善標準。
3. **三區工作台架構 (Game Workspace)**：
   - **Zone A（3D 遊戲場景）**：佔主畫面核心，以 Three.js 呈現明亮清爽的 3D 星際探測世界。
   - **Zone B（操作區）**：程式編輯器（Ctrl / ⌘ + Enter 執行）、執行回饋、變數盒子與 console.log 輸出。
   - **Zone C（任務資訊區）**：一句話任務目標、逐項打勾的通關要求、任務故事、觀念小教室與漸進提示。
4. **首頁星際地圖導航**：
   - 包含冒險起點、關卡星圖導航、學習進度條、音效開關與 JSON 存檔匯出/匯入。
5. **收合式 JavaScript 對照區**：
   - 預設收合，完成任務後展開比對，讓學生將直觀遊戲經驗自然連結至現實 JavaScript 語法。
6. **Open-Meteo 全球即時氣象 API 連線 (Level 8)**：
   - 串接真實公開天氣 API，支援逾時與離線教學模擬切換，帶領學生理解現代網路資料交換。
7. **金手指教師模式**：
   - 支援密令 `jaccis666`，可快速解鎖全部 9 個關卡，方便課堂示範與教學評量（提示也會全部開放）。
8. **零基礎友善的除錯體驗**：
   - 英文錯誤訊息翻成白話中文（例如「奧德賽號 is not defined」→「文字要用引號包起來」），並標在編輯器出錯的那一行。
   - 執行前偵測注音輸入法打出的全形符號（；（）＝「」），可一鍵修正。
   - 任務清單逐項打勾，沒過時標出「卡在這裡」；提示依失敗次數漸進解鎖（第 1 則免費，失敗 2、3 次再開放）。
   - 「變數盒子」顯示程式跑完後每個變數的值與型態；console.log 輸出直接顯示在執行按鈕下方。
   - 逐行高亮執行：按下執行後，編輯器會跟著 3D 動畫逐行亮起正在跑的那一行（迷宮關與每一步移動精準對齊）；跑完可用編輯器底部的工具列一步步前進／後退，看每一步執行前各變數的值（迴圈的 i、if 走進哪個分支一目了然）。出錯時也會保留出錯前的步驟。第 7 站（DOM 事件）因為由學生親手點擊觸發，不提供逐行追蹤。
9. **趣味與課堂管理**：
   - 每關 1~3 星並存檔，首頁顯示總星數；第 1 關取的船名一路沿用到每一關。
   - 錯誤圖鑑：遇到一種新錯誤就收集一張卡，把犯錯變成收藏。
   - 通關卡片附「出場券」小測驗與通關碼（例如 `05-3-K7QF`），老師可在教師密令視窗輸入船名與通關碼驗證。
   - 寬度不足 1200px（教室投影機）時，任務簡報自動收成右側抽屜。

## 🚀 九大完整教學關卡

| 關卡 | 主題 | 核心概念 | 遊戲互動機制 | 3D 視覺反饋 |
| :--- | :--- | :--- | :--- | :--- |
| **01** | **探測船通電自檢** | 變數與資料型態 (let/String/Number/Boolean) | 輸入船名＋功率設定＋防護罩開關 | 探測船通電自檢、功率燈號與防護罩激活 |
| **02** | **能源補給站** | 變數與參數運算 | 設定初始燃料、推進次數與速度計算位移 | 噴射藍色離子焰火，精準位移 24 單位並安全著陸平台 |
| **03** | **隕石避障** | 條件判斷 (if / else) | 條件判斷 (< 5 煞停、< 15 減速、否則全速前進) | 雷達波即時測距，遇近距隕石自動緊急剎車避碰 |
| **04** | **太空站跑酷** | 條件決策實戰 (else if / === / \|\|) | 撰寫 `decide(ahead)` 依前方地形判斷跳躍/滑行/疾跑，並受隱藏賽道檢驗 | 第三人稱 3D 視角追隨，探測車拋物線躍過斷崖與矮障、貼地滑行穿過高橫桿 |
| **05** | **迷宮巡航與迴圈** | 迴圈結構與路徑最佳化 (for) | 前進/轉彎＋for 迴圈巡航穿越 6x6 峽谷抵達 (4,4) | 探測船峽谷迷宮導航、避開岩石障礙抵達基地 |
| **06** | **模組裝載** | 函式與物件 (Objects & Methods) | 模組選型 (量子廣角光譜儀)、屬性設定與呼叫方法 | 旋轉全息雷達天線，釋放大型環狀脈衝波顯影星體 |
| **07** | **太空艙控制中心** | 事件與 DOM (addEventListener) | 下方接線＋上方 2D 網頁親手點擊/懸停/雙擊實驗 | 2D 儀表板網頁即時改寫 textContent、style、艙門 class 滑開 |
| **08** | **無人機編隊** | 陣列與迭代 (Array forEach) | 無人機陣列清單檢視、低電量安全閾值過濾與分派 | 4 架無人機分頭出動，低電量機回塢，其餘空域巡邏 |
| **09** | **星際氣象站** | API 與外部資料 (fetch & JSON) | 選擇測站、連線 Open-Meteo API、配置三條JSON路徑並選安全站發射 | 氣象雷達全向旋轉，高空無人機穿破白雲升空測繪 |

> 課堂 1-2 節速玩路線：L1 → L3 → L4(跑酷) → L7（L9 由教師 demo），其餘為課後自由探索。

## 🛠️ 本地開發與啟動

### 1. 環境需求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 2. 安裝依賴
```bash
npm install
```

### 3. 啟動開發伺服器
```bash
npm run dev
```
瀏覽終端提示之本地網址（預設 `http://localhost:5173` 或 `http://localhost:5174`）。

### 4. 執行單元測試
```bash
npm run test
```

### 5. 建置生產版本 (Production Bundle)
```bash
npm run build
```
輸出檔案位於 `dist/` 目錄，內含完整 HTML、CSS、JS 與無外部相依之純前端資源。

## ☁️ Cloudflare Pages 部署說明

本專案完全基於純靜態前端架構，100% 相容 Cloudflare Pages 靜態託管：

1. **登入 Cloudflare Dashboard** ➔ 選擇 **Workers & Pages** ➔ **Create application** ➔ **Pages** ➔ **Connect to Git**。
2. 選取本專案 Git 儲存庫。
3. **組態設定 (Build settings)**：
   - **Framework preset**：`Vite`
   - **Build command**：`npm run build`
   - **Build output directory**：`dist`
   - **Node.js Version (環境變數)**：`NODE_VERSION = 20`
4. 點擊 **Save and Deploy** 即可完成自動化 CI/CD 部署。
